# 大学课程学习资料库

这里用于整理和发布大学期间各门课程的学习资料，包括课程笔记、复习提纲、作业整理、实验报告模板、参考资料索引等。

## 目录结构

```text
.
├── courses/                 # 按学年、学期、课程分类的资料
│   └── 2026-spring/
│       └── example-course/
│           ├── notes/       # 课堂笔记、章节笔记
│           ├── assignments/ # 作业整理与思路
│           ├── labs/        # 实验资料、实验报告模板
│           ├── exams/       # 复习资料、往年题整理
│           └── resources/   # 参考链接、书单、资料索引
├── templates/               # 通用模板
└── docs/                    # 仓库说明与维护文档
```

## 命名建议

- 学期目录：`2026-spring`、`2026-fall`
- 课程目录：使用英文或拼音小写，用短横线连接，例如 `data-structures`、`linear-algebra`
- 笔记文件：`chapter-01.md`、`week-01.md`
- 作业文件：`assignment-01.md`
- 实验文件：`lab-01.md`

## 内容建议

每门课程可以包含：

- `README.md`：课程简介、教师/教材、考试形式、资料导航
- `notes/`：课堂笔记、知识点总结
- `assignments/`：作业题目整理、解题思路、代码
- `labs/`：实验要求、实验记录、报告模板
- `exams/`：复习提纲、题型整理、易错点
- `resources/`：参考链接、书籍、公开课程、工具说明

## 版权与学术诚信

请只上传你有权公开分享的内容。不要上传未经授权的教材扫描件、课件原文、付费资料、考试原题或他人的作业答案。

本仓库更适合发布自己的学习笔记、总结、代码实现、实验记录和公开资料链接。使用资料时请遵守所在学校和课程的学术诚信要求。

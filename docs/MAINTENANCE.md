# 维护指南

## 添加一门新课程

1. 在 `courses/学期/` 下创建课程目录。
2. 复制 `templates/course-readme.md` 到课程目录，并重命名为 `README.md`。
3. 根据课程需要创建 `notes/`、`assignments/`、`labs/`、`exams/`、`resources/` 等目录。
4. 在课程 `README.md` 中补充资料导航。

## 上传资料前检查

- 是否包含个人隐私信息？
- 是否包含老师或同学未授权公开的内容？
- 是否包含教材、课件、题库等可能受版权保护的原文？
- 是否可能违反课程的学术诚信要求？
